# v0.2 测试与审核清单

## 1. 测试目的

本清单用于验证当前工程原型是否可以进入单一患者短时测试。

当前阶段不评估“患者能否长期使用”，只评估：

- 摄像头和模型是否稳定。
- 眨眼短码是否可被可靠识别。
- 误触风险是否在可讨论范围内。
- 面部描边是否能帮助工程师和照护者判断信号质量。
- TTS 是否只在完成引导校准后的明确短语或确认后播报。

## 2. 测试角色

| 角色 | 责任 |
| --- | --- |
| 工程师 | 观察画面、FPS、EAR、短码、日志和错误信息 |
| 照护者 | 判断短语是否安全、可理解、符合护理场景 |
| 患者 | 只做低疲劳、可停止的短时动作测试 |

测试必须允许患者随时停止。出现疲劳、疼痛、焦虑、呼吸不适、明显眼干时立即停止。

通过标准：

- 不应出现语音误播。

- 面部描边应基本稳定。

## 6. 眨眼短码测试

每个动作最多测试 3 轮。患者疲劳时立即停止。

| 动作 | 目标结果 | 结果记录 |
| --- | --- | --- |
| 单次短眨 `.` | 无指令，不播报 | 通过 / 误触 / 未识别 |
| 单次长闭眼 `-` | 无全局指令，不播报 | 通过 / 误触 / 未识别 |
| 两次短眨 `..` | 校准前只记录；校准后显示并播报“我需要喝水或润口” | 通过 / 误触 / 未识别 |
| 三次短眨 `...` | 校准前只记录；校准后显示并播报“紧急求助，请马上查看” | 通过 / 误触 / 未识别 |
| 两次长闭眼 `--` | 校准前只记录；校准后播报休息并暂停 5 分钟 | 通过 / 误触 / 未识别 |
| 超过 3 个符号 | 短码过长，忽略 | 通过 / 误触 |

注意：三次短眨是高风险短语，测试前要告知照护者这是模拟。

## 8. 可选动作测试

可选动作默认关闭。只有完成引导校准，并且工程师或照护者明确同意时才逐个打开测试。

| 动作 | 测试目的 | 结果 |
| --- | --- | --- |
| 抬眉确认 | 抬眉触发“确认”；在确认窗口内可确认护理/体位提示 | 可用 / 不稳定 / 疲劳 |
| 张嘴吸痰 | 4 秒内两次张嘴保持，播报“我需要吸痰，请马上查看” | 可用 / 不稳定 / 非主动风险 |
| 摇头取消 | 摇头触发“否，不是，取消”；在确认窗口内取消 | 可用 / 不稳定 / 颈部疲劳 |
| 微笑表达 | 微笑触发“谢谢，可以，我还好” | 可用 / 不稳定 / 不建议 |

通过标准：

- 校准前，可选动作不应触发 TTS。
- 手动关闭时，可选动作不应触发 TTS。
- 开启后，静息 60 秒内不应出现动作误播。
- 张嘴吸痰必须验证“单次张嘴不播报，两次张嘴才播报”。

## 10. 停测条件

出现任一情况应停止测试：

- 患者疲劳、疼痛、焦虑、呼吸不适。
- 眼干、流泪、睁眼困难明显增加。
- 连续出现语音误播。
- 摄像头画面不稳定或描边明显漂移。
- 照护者认为当前短语可能造成误解。
