# v0.4 Action Text 与高级设置

## 1. 目标

v0.4 只做一件事：让照护者为每个已识别动作自定义一条表达文字，并保存到当前 Mac 浏览器本机。

```text
动作识别结果
→ action text
→ 屏幕显示
→ 语音播报
```

屏幕显示和语音播报使用同一句表达文字，不再分别设置。

## 2. 核心规则

1. 每个动作触发后必须有屏幕显示。
2. 每个动作触发后必须有语音播报。
3. 高级设置只输入一条表达文字。
4. 高级设置不能关闭显示，不能关闭播报。
5. 高级设置不允许普通用户修改 EAR、blendshape、头部姿态、动作窗口等检测参数。
6. 所有默认含义必须可以一键恢复。

## 3. 配置结构

高级设置保存的是动作 ID 到表达文字的映射：

```js
{
  "smile_double_love": "我爱你",
  "mouth_double_open_suction": "我需要吸痰，请马上查看"
}
```

代码内部仍可保留动作名称、分类、输入来源和说明，但高级设置不暴露这些字段。

## 4. 高级设置界面

每个动作一行：

```text
动作名称
表达文字输入框
测试播报
恢复默认
```

不显示这些控件：

```text
屏幕显示输入框
语音播报输入框
关闭播报
只显示不播报
禁用动作
识别阈值
确认流程开关
```

## 5. 默认动作含义

| 动作 | 默认表达文字 |
| --- | --- |
| 短眨2次 | 我需要帮助，请过来一下 |
| 短眨3次 | 紧急求助，请马上查看 |
| 长闭眼2次 | 我想休息 |
| 短眨 + 长闭眼 | 我想挠痒痒 |
| 长闭眼 + 短眨 | 我想调整体位 |
| 抬眉 | 是，确认 |
| 张嘴2次 | 我需要吸痰，请马上查看 |
| 摇头 | 否，不是，取消 |
| 微笑 | 谢谢，可以，我还好 |
| 微笑2次 | 我爱你 |

## 6. 本地保存

使用 localStorage 保存用户改过的表达文字：

```text
alsFacialAac.actionText.v1
```

保存内容只包含和默认值不同的动作：

```js
{
  "smile_double_love": "我爱你们"
}
```

启动合并顺序：

```text
代码默认配置
→ 本机保存的表达文字
→ 当前运行状态
```

旧的双字段配置键会被清理：

```text
alsFacialAac.actionConfig.v2
```

## 7. 导出 / 导入

导出内容只包含动作表达文字，不包含摄像头、阈值、模型或患者测试记录。

导入时必须校验：

- `id` 必须存在于默认动作配置中。
- 表达文字必须是非空文本。
- 未识别字段直接忽略。
- 导入后立即刷新动作说明。

为兼容短期测试文件，导入时可以读取旧格式中的 `text`、`speechText` 或 `displayText`，但保存和导出只使用新的单字段格式。

## 8. 当前实现状态

已实现：

- 高级设置面板。
- 每个动作一个表达文字输入框。
- 屏幕显示和语音播报使用同一句。
- 保存到本机 `localStorage`。
- 取消未保存修改。
- 单项恢复默认。
- 全部恢复默认。
- 导出 JSON。
- 导入 JSON 并保存。
- 测试播报。

仍需真实使用测试：

- 照护者是否能理解“保存 / 取消修改 / 恢复默认”的区别。
- 自定义长文本是否会让普通界面换行过多。
- 导入/导出配置在另一台 Mac 上是否符合预期。

## 9. 本阶段不做

- 不做通用扫描选择模式。
- 不做护理菜单。
- 不做多患者档案。
- 不做云同步。
- 不让用户关闭显示或语音播报。
- 不让用户修改动作识别参数。
