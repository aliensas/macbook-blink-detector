# iOS 版本 v0.1 计划

## 1. 分支目标

本分支用于探索 iPhone / iOS 版本，不影响 Mac 本地版。

分支名：

```text
codex/ios-aac-app-v01
```

代码路径：

```text
ios/
```

文档路径：

```text
docs/ios/
```

## 2. 产品定位

iOS 版本仍然定位为：

```text
ALS 面部微动作 AAC 输入原型
```

不是医疗诊断工具，不直接替代专业 AAC 设备。目标是把患者可控的低疲劳面部动作，转换成文字和语音表达。

## 3. 第一阶段功能范围

先迁移已经在 Mac 版验证过的核心闭环：

- 摄像头启动和权限提示。
- 人脸关键点检测。
- 眨眼短码。
- 长闭眼、短眨组合。
- 输入管理。
- 抬眉、张嘴、微笑、摇头可选开关。
- 高级设置：自定义动作表达文字。
- 二级选择：挠痒痒、调整体位。
- 本机保存配置。
- 文字显示和语音播报。

第一阶段暂不做：

- App Store 发布。
- 云端账户。
- 多患者云同步。
- 远程照护通知。
- 医疗设备联动。

## 4. 技术路线

建议先走最小风险路线：

```text
现有 Web 逻辑
  -> iOS 专用移动端页面
  -> iPhone Safari 真机验证
  -> Capacitor / Xcode 打包
  -> iPhone 真机安装测试
```

这样可以先判断 iPhone 上的摄像头、MediaPipe、TTS、性能和布局是否可接受，再决定是否投入更重的原生开发。

## 5. 关键技术风险

需要重点验证：

- iPhone 前置摄像头权限是否稳定。
- iOS 浏览器 / WebView 中 MediaPipe WASM 性能是否足够。
- 横屏和竖屏下摄像区域是否稳定。
- 长文字输出是否导致布局跳动。
- TTS 首次播报延迟是否可接受。
- 本地存储是否可靠保存患者配置。
- iOS 后台、锁屏、来电、切应用时是否会中断摄像头。

## 6. iPhone 适配重点

优先适配：

- iPhone 15 Pro
- iPhone 15 Pro Max

布局原则：

- 摄像画面固定比例，不随文字和按钮变化突然缩放。
- 竖屏优先，横屏可用。
- 重要输出文字在拇指操作区域上方。
- 输入管理和高级设置避免过深层级。
- 常用动作说明只显示已开启动作。
- 工程测试记录不要干扰患者主界面。

## 7. 测试顺序

1. iPhone Safari 打开本地/局域网地址，验证摄像头。
2. 验证眨眼短码。
3. 验证输入管理。
4. 验证抬眉、张嘴、微笑、摇头。
5. 验证二级选择。
6. 验证语音播报。
7. 验证竖屏和横屏。
8. 再决定是否打包为 iOS App。
