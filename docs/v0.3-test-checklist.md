# v0.3 Mac 本地测试清单

本清单只用于当前 Mac 本地版测试。旧版规则已删除；历史内容如需恢复，请从 GitHub 回滚。

## 测试前确认

- 打开 `http://127.0.0.1:5173/`。
- 右侧“当前动作说明”应显示当前规则。
- 点击“启动”，允许摄像头权限。
- 完成引导校准并点击“完成确认”。
- 每个动作最多连续测试 3 次；患者疲劳时立即停止。
- 长闭眼按“闭眼约 1 秒后睁开”测试；有效范围约 `0.7-2.8 秒`，系统在睁开后识别。
- `短眨 + 长闭眼` 按“短眨并睁开 -> 2.5 秒内长闭眼约 1 秒 -> 睁开”测试。

## 眨眼短码

| 动作 | 目标结果 | 记录 |
| --- | --- | --- |
| 单次短眨 | 忽略，不播报 | 通过 / 误触 / 未识别 |
| 单次长闭眼 | 单独不播报；可作为长闭眼2次的第 1 次 | 通过 / 误触 / 未识别 |
| 短眨2次 | 显示并播报“我需要帮助，请过来一下” | 通过 / 误触 / 未识别 |
| 短眨3次 | 显示并播报“紧急求助，请马上查看” | 通过 / 误触 / 未识别 |
| 长闭眼2次 | 显示并播报“我想休息”；不自动暂停识别 | 通过 / 误触 / 未识别 |
| 短眨 + 长闭眼 | 显示并播报“我想挠痒痒” | 通过 / 误触 / 未识别 |
| 长闭眼 + 短眨 | 显示并播报“我想调整体位” | 通过 / 误触 / 未识别 |

## 重点观察

- 是否出现非当前规则的旧版语义。
- 长闭眼2次是否会导致识别暂停。
- 短眨+长闭眼是否稳定触发挠痒痒。
- 张嘴2次和摇头是否容易误触。
- 微笑单次等待 1.8 秒是否可以接受。
- TTS 播报是否明显慢于文字显示。
