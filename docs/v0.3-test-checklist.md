# v0.3 Mac 本地测试清单

本清单只用于当前 Mac 本地版测试。旧版规则已删除；历史内容如需恢复，请从 GitHub 回滚。

## 测试前确认

- 打开 `http://127.0.0.1:5173/`。
- 右侧“当前动作说明”应显示当前规则。
- 点击“启动”，允许摄像头权限。
- 完成引导校准并点击“完成确认”。
- 每个动作最多连续测试 3 次；患者疲劳时立即停止。
- 长闭眼按“闭眼约 1 秒后睁开”测试；有效范围约 `0.7-2.8 秒`，系统在睁开后识别。
- `短眨 + 长闭眼` 按“短眨并睁开 -> 2.5 秒内长闭眼约 1 秒 -> 睁开”测试。

## 可选动作

测试前逐项勾选对应输入。

输入管理菜单：

- 点击“输入管理”，确认出现轮询选项。
- 两次短眨选择当前高亮项，确认可切换抬眉、张嘴、微笑、摇头；抬眉已开启时，也可用抬眉选择。
- 选择“仅用眨眼”后，抬眉、张嘴、微笑、摇头应全部关闭，眨眼短码仍保持开启。
- 单次长闭眼应退出输入管理。
- 输入管理中开启摇头后，轻微摇头不应退出输入管理；摇头只在挠痒痒/调整体位等普通二级选择里取消。
- 完成校准确认后，测试 `长闭眼 + 长闭眼 + 短眨`，第二次长闭眼后约 `1.6 秒` 内接短眨，应进入输入管理菜单。

- 抬眉：头部尽量稳定，轻抬眉约 `0.25 秒` 后放松；再单独测试上下点头，确认不会误触抬眉。
- 张嘴2次：微张嘴约 `0.2 秒` 后闭合，`6 秒` 内重复两次；观察是否还会带动抬眉误报。
- 微笑：先保持自然表情约 1 秒，再轻微闭嘴微笑约 `0.25 秒` 后放松；观察嘴角横向距离增长是否能触发，左右摇头时不应触发。
- 摇头：极轻微左-右-左或右-左-右，`4 秒` 内完成。

| 动作 | 目标结果 | 记录 |
| --- | --- | --- |
| 抬眉 | 显示并播报“是，确认” | 通过 / 误触 / 未识别 |
| 张嘴2次 | 显示并播报“我需要吸痰，请马上查看” | 通过 / 误触 / 未识别 |
| 摇头 | 显示并播报“否，不是，取消” | 通过 / 误触 / 未识别 |
| 微笑 | 约 2.4 秒后显示并播报“谢谢，可以，我还好” | 通过 / 反应慢 / 误触 / 未识别 |
| 微笑2次 | 显示并播报“我爱你” | 通过 / 误触 / 未识别 |
| 上下点头 | 不应触发抬眉“是，确认” | 通过 / 误触 |

## 重点观察

- 是否出现非当前规则的旧版语义。
- 长闭眼2次是否会导致识别暂停。
- 短眨+长闭眼是否稳定触发挠痒痒。
- 张嘴2次和微笑是否仍会互相混淆。
- 摇头是否能用更小幅度触发，且不会因画面位移误触，也不会触发微笑。
- 微笑单次等待 2.4 秒是否可以接受。
- 摄像头画面是否还会明显自动缩放；若出现“画面稳定中”，观察这段时间是否不再触发可选动作。
- TTS 播报是否明显慢于文字显示。
