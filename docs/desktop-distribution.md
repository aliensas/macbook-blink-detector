# Mac 桌面版分发说明

目标：把 ALS 面部微动作 AAC 原型封装成其他 Mac 可以直接打开的桌面应用，避免使用者安装 Node、运行命令或启动本地开发服务器。

## 使用方式

开发者在本项目目录运行：

```bash
npm install
npm run dist:mac
```

完成后在 `release/` 目录中找到 `.dmg` 文件，发给使用者安装。

使用者步骤：

1. 打开 `.dmg`。
2. 将应用拖到 Applications/应用程序。
3. 首次打开时允许摄像头权限。
4. 启动摄像头，完成一次患者校准和确认。
5. 同一患者以后再次打开会自动沿用本机校准档案。

如果 macOS 提示应用来自未识别开发者，右键应用并选择“打开”，或到“系统设置 > 隐私与安全性”允许打开。正式给更多家庭使用前，建议做 Apple Developer ID 签名和 notarization。

## 当前封装内容

- Electron 桌面外壳。
- Vite 构建后的前端页面。
- MediaPipe FaceLandmarker 模型。
- MediaPipe wasm 文件。
- 摄像头权限请求说明。
- 本地患者校准档案保存逻辑。

## 本地校准档案

校准档案只保存在当前电脑的应用本地存储中，不上传服务器。保存内容包括：

- 眨眼阈值。
- 闭眼帧数。
- 睁眼/闭眼 EAR 样本。
- 短眨/长闭眼时长样本。
- 工程测试模式下的短码测试通过状态；普通用户界面默认不显示工程测试。

更换患者、患者疲劳状态明显变化、摄像头位置变化很大、光线条件变化很大时，照护者应点击“重置”并重新校准。

## 验证清单

打包后至少检查：

- 应用可双击打开。
- 首次启动会请求摄像头权限。
- 摄像头画面能显示。
- 面部描边能显示。
- 完成一次校准后重启应用，状态仍为“已确认”。
- 点“重置”后会清除本地校准档案。
- 短眨2次播报“我需要帮助，请过来一下”。
- 三短眨播报“紧急求助，请马上查看”。
- 两次长闭眼应被忽略，不显示、不播报；闭眼 8 秒以上即使未睁开也进入系统安静模式。
- 短眨+长闭眼播报“我想挠痒痒”。
